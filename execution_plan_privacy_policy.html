隐私政策

生效日期：2026年7月26日

欢迎使用「执行派」（以下简称"本应用"）。我们深知个人信息对您的重要性，并会尽力保护您的隐私。本政策向您说明我们如何处理您的信息。

一、我们收集的信息

1.1 您主动创建并存储在本地的内容

本应用的核心数据（包括您的计划、执行步骤、携带物品、完成指标、备注等）均仅存储在您设备本地的数据库（SQLite）中，不会上传到我们的服务器，我们也不会读取或收集您在这些内容中填写的任何信息。

1.2 崩溃与异常日志（经您同意）

为提升应用的稳定性、定位并修复崩溃问题，在您同意本隐私政策后，我们会通过腾讯 Bugly SDK 收集并上报以下匿名技术信息：

  • 设备型号、操作系统版本、应用版本；
  • 发生崩溃或异常时的堆栈信息（stack trace）、运行日志（不含您计划的具体内容）；
  • 用于问题定位的粗略运行环境信息。

这些信息不包含您的计划、步骤、备注等任何业务内容，属于匿名崩溃诊断数据。如您未同意本政策（在首次弹窗中选择"不同意"），Bugly 不会被初始化，我们也不会收集或上报任何此类信息。

二、我们使用的权限

  • 存储权限（Android）：用于在本机保存应用运行所需的本地数据。

本应用不使用相机、麦克风、定位、通讯录、日历等任何敏感权限。

三、我们使用的第三方 SDK

本应用集成了以下第三方 SDK，其收集的信息仅用于对应目的，受各自隐私政策约束：

SDK提供方用途收集的信息
腾讯 Bugly 腾讯 崩溃/异常监控与诊断 设备型号、系统版本、应用版本、匿名崩溃堆栈（不含业务内容）
关于广告：为支持本应用的持续运营，我们计划后续版本接入广告 SDK（如穿山甲、优量汇等）。届时本政策将同步更新广告 SDK 的名称、提供方及其收集的信息（通常包括广告标识符、设备信息等），并在应用内重新征得您的同意。当前版本暂不展示广告。

第三方 SDK 的隐私政策：

  • 腾讯 Bugly：https://privacy.qq.com/

四、数据的存储与安全

您的计划类业务数据仅存储在本地设备，不会离开您的设备；崩溃日志仅在您同意后由 Bugly 匿名上报。您可随时在应用内逐条删除计划，或卸载本应用以清除全部本地数据。我们会采取合理措施保护信息的安全，但请您理解互联网传输仍存在一定风险。

五、儿童隐私

本应用不专门面向儿童，我们不会故意收集儿童的个人信息。如您为未成年人，请在监护人陪同下使用本应用。

七、政策的更新

我们可能适时修订本隐私政策。涉及第三方 SDK、信息收集范围或用途等重大变更时，我们会在应用内重新提示您阅读并征得同意；更新后的政策将在应用内及本页面公布，并在生效日期起适用。
